💡 KEY POINTS TO REMEMBER
═══════════════════════════════════════════════════════════════════════════

🔑 The main() function has 5 essential steps:
   1. rclpy.init()           ← Initialize ROS2
   2. node = Class()         ← Create the node
   3. rclpy.spin(node)       ← Run forever (THIS IS WHERE IT LISTENS!)
   4. node.destroy_node()    ← Cleanup
   5. rclpy.shutdown()       ← Shutdown

🔑 Subscribing and listening happens automatically via callbacks:
   • create_subscription() sets up listening
   • Callback function fires when message arrives
   • Automatically processes incoming messages
   • Increments the counter
   • Logs the action

🔑 Receives messages from the /chatter topic:
   • Message type: std_msgs/msg/String
   • Format: "Hello, world! {counter}"
   • Rate: 1 message per second (from publisher)

🔑 Subscriber vs Publisher:
   • Publisher SENDS messages on a schedule
   • Subscriber RECEIVES messages as they arrive
   • Both use same initialization pattern
