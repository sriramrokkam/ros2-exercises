QUICK FACTS ABOUT SUBSCRIBERS
═══════════════════════════════════════════════════════════════════════════

🔹 What is a Subscriber?
   - A node that listens to messages on a topic
   - Receives messages sent by publishers
   - Automatically calls a callback function when messages arrive

🔹 The 5 Steps in main():
   1. rclpy.init(args=args)         → Initialize ROS2
   2. node = SimpleSubscriber()     → Create subscriber node
   3. rclpy.spin(node)              → Listen (runs forever!)
   4. node.destroy_node()           → Cleanup
   5. rclpy.shutdown()              → Shutdown ROS2

🔹 Key Methods:
   - create_subscription()  → Start listening to a topic
   - listener_callback()    → Function called when message arrives

🔹 The Callback Flow:
   1. Publisher sends message to /chatter topic
   2. Subscriber receives the message
   3. listener_callback() is automatically called
   4. Message data is processed
   5. Counter increments and message is logged

KEY CODE SNIPPETS
═══════════════════════════════════════════════════════════════════════════

Create a Subscription:
  self.subscription = self.create_subscription(
      String,                    # Message type
      'chatter',                # Topic name
      self.listener_callback,   # Callback function
      10)                       # Queue size

The Callback Function:
  def listener_callback(self, msg):
      self.counter += 1
      self.get_logger().info(f'Received message #{self.counter}: {msg.data}')


COMMON ISSUES AND FIXES
═══════════════════════════════════════════════════════════════════════════

Issue: "Received message #1" never appears
  ↓ Solution: Run the publisher in Terminal 1 first

Issue: "No ROS2 environment" error
  ↓ Solution: Run: source /opt/ros/humble/setup.bash

Issue: "Package not found"
  ↓ Solution: Run: colcon build && source install/setup.bash

Issue: Module not found 'rclpy'
  ↓ Solution: Make sure ROS2 is installed and setup.bash is sourced

Issue: Multiple subscribers receiving same message
  ↓ This is NORMAL! All subscribers get every message
