📝 WHAT THE main() FUNCTION DOES (5 Steps):

   Step 1: rclpy.init()
           └─ Initialize ROS2 middleware

   Step 2: node = SimplePublisher()
           └─ Create the publisher node
           └─ Sets up timers and callbacks

   Step 3: rclpy.spin(node)
           └─ Run the node (infinite loop)
           └─ Execute timers and publish messages
           └─ Runs until Ctrl+C is pressed

   Step 4: node.destroy_node()
           └─ Cleanup resources

   Step 5: rclpy.shutdown()
           └─ Shutdown ROS2

🆘 TROUBLESHOOTING:

   "ros2: command not found"
   → Run: source install/setup.bash

   "Package not found"
   → Run: colcon build

   "No messages appearing"
   → Check if publisher is running in another terminal

   "Port already in use"
   → Kill previous processes: pkill -f ros2
