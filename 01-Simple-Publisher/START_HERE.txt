💡 KEY POINTS TO REMEMBER
═══════════════════════════════════════════════════════════════════════════

🔑 The main() function has 5 essential steps:
   1. rclpy.init()           ← Initialize ROS2
   2. node = Class()         ← Create the node
   3. rclpy.spin(node)       ← Run forever (THIS IS WHERE IT PUBLISHES!)
   4. node.destroy_node()    ← Cleanup
   5. rclpy.shutdown()       ← Shutdown

🔑 Publishing happens automatically via timer:
   • Timer fires every 1 second
   • Calls timer_callback() automatically
   • Creates and publishes a message
   • Increments the counter
   • Logs the action

🔑 Messages go to the /chatter topic:
   • Message type: std_msgs/msg/String
   • Format: "Hello, world! {counter}"
   • Rate: 1 message per second

🔑 Both Python and C++ work identically:
   • Same logic flow
   • Same behavior
   • Same output
   • Just different syntax
